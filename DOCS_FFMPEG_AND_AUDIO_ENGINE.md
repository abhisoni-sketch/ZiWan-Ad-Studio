# 🎬 Procedural FFmpeg Compositing & Audio Engine Documentation

This document explains the procedural multi-pass rendering pipeline, audio time-stretching algorithms, and subtitle overlay drawing executed by the **Master Stitcher Engine** ([backend/agents/stitcher.py](file:///Users/abhisoni/Documents/Ad_Creator/forPublicgit/backend/agents/stitcher.py)).

---

## 1. Multi-Pass Video Compositing Architecture

The video assembly pipeline transforms individual scene video clips generated by Vertex AI (Veo 3.1 Fast / Omni Flash) into a cohesive 1080p master commercial using a 4-stage pipeline:

```
[Raw Scene Video Clips] ---> (Stage 1: Normalize Resolution & FPS)
                             ---> (Stage 2: Voiceover Audio Time-Stretch)
                                  ---> (Stage 3: Subtitle Overlay Drawing)
                                       ---> (Stage 4: Audio Mix & Master Stitch) ---> [Final MP4]
```

### Stage 1: Resolution & Aspect Ratio Standardization
All input video clips are normalized to **1920x1080 (16:9 Landscape)** or **1080x1920 (9:16 Portrait)** at 30 FPS using FFmpeg `scale`, `pad`, and `fps` filters:

```bash
ffmpeg -i input_clip.mp4 \
  -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=30" \
  -c:v libx264 -preset fast -crf 18 \
  normalized_clip.mp4
```

## 2. Audio Time-Stretching & Alignment (`atempo` / `rubberband`)

To ensure synchronized voiceover delivery across 60-second commercials without pitch distortion:
* If generated Gemini Flash TTS audio duration differs from visual scene clip duration, the audio engine applies dynamic time-stretching using the FFmpeg `atempo` filter:

$$\text{Tempo Ratio} = \frac{\text{Audio Duration}}{\text{Target Scene Duration}}$$

```bash
# Example: Accelerate audio by 1.15x without altering pitch
ffmpeg -i scene_voiceover.wav \
  -filter:a "atempo=1.15" \
  stretched_voiceover.wav
```

## 3. Procedural Typography & Subtitle Overlays

Subtitles and promotional banner callouts are drawn procedurally using FFmpeg `drawtext` filters with custom font rendering, background bounding boxes, and shadow offsets:

```bash
ffmpeg -i scene.mp4 \
  -vf "drawtext=fontfile=PlusJakartaSans-Bold.ttf:text='Lustrous Silk Saree':x=(w-text_w)/2:y=h-150:fontsize=42:fontcolor=white:box=1:boxcolor=black@0.6:boxborderw=10" \
  -c:a copy output_subtitled.mp4
```

## 4. Multi-Track Audio Mixing Engine

The audio engine combines 3 distinct audio channels:
1. **Primary Voiceover Track:** High-priority narration generated by Gemini Flash TTS (`vol=1.0`).
2. **Background Music Track (BGM):** Instrumental soundtrack ducked automatically under voiceover (`vol=0.25`).
3. **Sound Effects (SFX):** Product transition cues (`vol=0.5`).

```bash
ffmpeg -i video.mp4 -i voiceover.wav -i bgm.mp4 \
  -filter_complex "[1:a]volume=1.0[vo]; [2:a]volume=0.25[bgm]; [vo][bgm]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" \
  -c:v copy -c:a aac -b:a 192k \
  final_commercial.mp4
```
